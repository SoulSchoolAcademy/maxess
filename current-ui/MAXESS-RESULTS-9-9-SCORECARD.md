## 9.5 acceptance gate

Must verify:

1. First-screen reveal feels premium and immediate.
2. Pattern statement produces recognition rather than generic praise.
3. DNA fingerprint is legible and visually distinctive on desktop and mobile.
4. Five dimensions read as one system.
5. One next action is obvious without scrolling confusion.
6. Naya receives the same result object and does not ask for a reset.
7. No console errors.
8. No iframe or DOM scraping dependencies.
9. All buttons have valid destinations or deterministic actions.
10. Reduced-motion mode remains coherent.
11. Mobile layout has no overflow or clipped controls.
12. Actual target result payload renders correctly, not only demo data.
