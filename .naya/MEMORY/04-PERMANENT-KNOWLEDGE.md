# PERMANENT KNOWLEDGE

This file contains durable lessons that have earned promotion beyond ordinary notes.

## PROMOTION STANDARD

A lesson may be promoted when it is:

- true or strongly supported;
- materially useful to future work;
- sufficiently generalizable;
- compatible with higher-priority governance;
- unlikely to create harmful unintended constraints;
- supported by evidence, repeated observation, or a clearly important principle.
