## ZERO-CHANGE RULE

If a requested implementation produces no material change, record:

`STATUS: BLOCKED — ZERO-CHANGE EXECUTION`

Do not report the execution as complete.

## ITERATION RULE

Version numbers and execution numbers are not interchangeable.

Execution # measures attempts/iterations.

Version measures the artifact state.

A new execution must explicitly state both when both exist.
