# NAYA MEMORY — READ FIRST

Status: ACTIVE MEMORY ROUTER

This directory contains the living learning memory for the MAXESS/Naya system.

## RULE

Do not read every historical note by default.

Read the smallest set that preserves the context required for the current task.

If the task is consequential and uncertainty remains, read more rather than guessing.

## ROUTING

### For any consequential execution
Read:

1. `.naya/07-MEMORY-SYSTEM.md`
2. this file
3. `04-PERMANENT-KNOWLEDGE.md`
4. `05-FAILURE-PATTERNS.md`
5. `06-SUCCESS-PATTERNS.md`
6. the latest applicable `02-DAILY-SYNTHESIS/` entry
7. the applicable project/role memory identified by `.naya/06-PROJECT-MEMORY-INDEX.md`

### For a new failure or regression
Also read:

- `05-FAILURE-PATTERNS.md`
- `08-EXECUTION-LEDGER.md`
- the relevant prior execution record

### For a new design or architecture decision
Also read:

- `07-DECISION-MEMORY.md`
- `06-SUCCESS-PATTERNS.md`
- relevant project architecture memory

### For daily closeout
Read:

- `01-SMART-NOTES.md`
- today's execution records in `08-EXECUTION-LEDGER.md`
- unresolved items from the active project memory

Then write/update `02-DAILY-SYNTHESIS/`.

### For weekly synthesis
Read:

- the week's daily syntheses
- `05-FAILURE-PATTERNS.md`
- `06-SUCCESS-PATTERNS.md`
- `07-DECISION-MEMORY.md`
- `09-EVOLUTION-LOG.md`

Then update `03-WEEKLY-SYNTHESIS/` and promote only durable learning.

## MEMORY HIERARCHY

```text
RAW SMART NOTES
      ↓
DAILY SYNTHESIS
      ↓
PATTERNS / DECISIONS
      ↓
PERMANENT KNOWLEDGE
      ↓
SAFEGUARDS
      ↓
GOVERNANCE / SYSTEM EVOLUTION
```

## DO NOT

- copy the same lesson into multiple files without a reason;
- treat every conversation detail as permanent memory;
- overwrite older learning without preserving history;
- promote assumptions as facts;
- create rules that conflict with higher-priority governance;
- keep stale lessons active when verified evidence has changed them.

## MEMORY COMMAND RESULT

When asked to “add a note,” the executor should produce a structured note containing:

- DATE
- CONTEXT
- OBSERVATION
- LESSON
- WHY IT MATTERS
- CATEGORY
- SOURCE / EXECUTION
- PROMOTION LEVEL
- FOLLOW-UP ACTION

If the lesson is clearly reusable, propose or apply the appropriate promotion.
