# DAILY SYNTHESIS

Each day gets one synthesis file: `YYYY-MM-DD.md`.

The synthesis is the compact starting context for the next day.

## TEMPLATE

# DAILY SYNTHESIS — YYYY-MM-DD

## 1. WHAT HAPPENED

## 2. WHAT CHANGED

## 3. WHAT WE LEARNED

## 4. WHAT WORKED

## 5. WHAT FAILED

## 6. ROOT CAUSES

## 7. NEW SAFEGUARDS

## 8. IMPORTANT DECISIONS

## 9. OPEN ISSUES

## 10. NEXT-DAY STARTING CONTEXT

## 11. MEMORY PROMOTIONS

List any lessons promoted to pattern, safeguard, permanent knowledge, or governance.

## 12. SOURCE REFERENCES

Link to execution records, files, commits, tests, and relevant smart notes.
