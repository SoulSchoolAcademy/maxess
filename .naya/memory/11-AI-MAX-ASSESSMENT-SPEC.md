# 11 — AI MAX ASSESSMENT SPEC

Status: LOCKED PRODUCT MEMORY
Version: 1.0

## Product
AI MAX is the flagship MAXESS assessment.
Working public-facing concept: “What’s Your ChatGPT Score?” / “Discover how well you’re really using AI.”
Purpose: measure practical effectiveness when working with ChatGPT/AI, teach useful principles during the assessment, produce an honest score and diagnosis, and connect the user to a personalized AI mastery path.

## Experience promise
15 questions. About 3 minutes. No trick questions. No bad answers. Choose what is most like what you actually do today, not what you think you should do.
Assessment should teach while measuring: Teach → Ask → Answer → Tiny insight → Next.
The experience should produce recognition rather than judgment: “Maybe I’m not getting poor AI results because AI sucks. Maybe there’s a better way to work with it.”

## Five dimensions
1. Direction — knowing what the desired outcome is and directing AI toward it.
2. Context — giving AI the information, audience, situation, limits, examples, and preferences that materially affect the result.
3. Collaboration — using AI to explore, challenge, reason, compare viewpoints, and support decisions while keeping human responsibility.
4. Evaluation — judging whether output is actually good against relevant standards, not merely whether it looks good.
5. Iteration — improving results deliberately, preserving what works and changing what needs improvement.

## Current 15-question mapping
Direction: Q1–Q3.
Context: Q4–Q6.
Collaboration: Q7–Q9.
Evaluation: Q10–Q12.
Iteration: Q13–Q15.
Each dimension is intended to contribute 20% of the overall score.

## Question design principles
Questions should measure current behavior, not theoretical knowledge.
Answer positions should not obviously reveal the “best” answer.
Use realistic situations rather than jargon.
Avoid shame or intelligence framing.
Every question should earn its place by measuring a meaningful behavior or teaching a useful principle.

## Current question-level teaching concepts
Q1: clearer destination → better AI direction.
Q2: define what the finished result should accomplish.
Q3: identify exactly where an output missed the goal.
Q4: relevant context matters more than simply more context.
Q5: audience changes what good output means.
Q6: provide important information up front when it can change the answer.
Q7: AI can be used as a thinking partner, not only an answer engine.
Q8: deliberately challenge assumptions instead of seeking confirmation.
Q9: AI supports decisions; the human remains responsible for final judgment.
Q10: evaluate output against goal, audience, accuracy, usefulness and quality.
Q11: ask AI to critique its own work.
Q12: “Why isn’t this a 10?” turns generation into improvement.
Q13: purposeful iteration, not endless rewriting.
Q14: preserve strengths while improving weaknesses.
Q15: become a better director of intelligence rather than merely a better prompt writer.

## Scoring
Current supplied answer key exists in source material. It must be treated as configuration, not UI copy. Before production, normalize response values to a common 0–100 contribution so questions with multiple plausible high answers do not distort dimension weighting.
Score must be deterministic: same responses → same result.
Do not invent scores or use arbitrary result inflation.

## Mastery levels
Foundation: 0–49.
Developing: 50–74.
Advancing: 75–89.
Mastering: 90–100.
Mastering is not “finished”; it means ready for a higher level of mastery.

## Assessment privacy / honesty
Tell participants that answers are intended to help them understand current habits, not intelligence or worth. Encourage honest behavior reporting rather than aspirational answers.
No email gate should interrupt the primary assessment conversion. Intended journey: Assessment → Results → Free Trial.

## Result promise
The user should leave with: score, level, strongest capability, biggest opportunity, “OH… THAT’S WHY” pattern insight, personalized next move, 18-area pathway, and optional Naya continuation.
The assessment should provide genuine value even if the user never purchases or joins anything.
