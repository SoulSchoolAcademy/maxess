# 12 — HUMAN MAXIMUS AI MASTER KEY

Status: LOCKED OPERATING DOCTRINE
Version: 1.0

## Purpose
The Master Key teaches humans HOW to work with AI. It is not a prompt library; it is a practical operating system for turning human intention into exceptional AI-assisted results.

## Core principle
Do not optimize for better prompts alone. Become a better director of intelligence.

Human provides intention, direction, judgment and approval.
AI/Naya provides reasoning, organization, research, creation, analysis, critique and iteration.
Specialized mastery keys provide domain-specific expertise.
Scorecards define quality.
Iteration creates excellence.
Humans remain responsible for consequential judgment and final approval.

## Universal workflow
1. KNOW — What am I trying to create or accomplish?
2. TELL — Tell Naya the destination in natural language.
3. ASK — Let Naya ask only the questions required to materially improve the result.
4. CREATE — Let Naya do the work it can reasonably do.
5. SCORE — Evaluate the result against appropriate quality criteria.
6. IMPROVE — Ask why it is not a 10, preserve strengths, fix weaknesses, iterate.
7. FREEZE — When the result meets the required standard, approve it as the current version.

Internal craftsmanship loop may add VERIFY / REGRESSION before FREEZE.

## Universal principles
- Understand the real outcome, not just the literal request.
- Challenge assumptions and identify missing information.
- Ask only questions that materially improve the result.
- Let AI do work it can reasonably perform instead of forcing unnecessary human effort.
- The first version is a starting point, not proof of completion.
- Never improve blindly; identify what works, what does not, why, and what should change.
- Preserve what already works.
- Scorecards are better than vague “make it better” requests.
- “Why isn’t this a 10?” is a core improvement question, not a demand for fake perfection.
- Quality is purpose-relative; not every task needs a 10/10.
- The user should receive value even when no purchase follows.

## Master Key philosophy
AI is the engine. The human is the director.
The goal is not more AI. The goal is better results.
The least human effort should reasonably produce the highest-quality result.

## Human Maximus standard
Serve humans. Tell the truth. Think deeply. Simplify intelligently. Build beautifully. Optimize relentlessly. Ship AAA. Scale wisdom.
