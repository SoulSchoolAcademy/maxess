# 21 — PRO MAX PLAYER / BLACK DIAMOND ROYAL UI STANDARD

## Purpose

The Pro Max Player is a flagship application surface. Important controls must feel tactile, premium, obvious and consistent rather than like generic browser buttons.

## Black Diamond Royal button formula

Premium buttons may use six layers:
1. Deep black-glass, royal-purple-glass or diamond-white base.
2. Metallic platinum or controlled gold-platinum outer frame.
3. Inner illuminated rim.
4. Raised/beveled face.
5. Directional top-edge highlight.
6. Floating shadow plus restrained aura.

The physical-object test is mandatory:

> It should feel like a button the user wants to press.

## Button hierarchy

### Royal Purple Primary
Strongest command: Play, Resume, Continue, Begin Journey, Enter Pro Max.

### Black Diamond Primary
Strong premium secondary: Install App, Explore, Share, Request Topic, Open Full Player, Menu.

### Diamond White Conversion
Purchase/membership/access: Start Free Trial, Upgrade, Join, Unlock Max Level.

### Black Utility
Previous, Next, Rewind, Forward, Repeat, Shuffle, Volume, Favourite, Add, Close.

### White Utility
Use sparingly when contrast or confirmation requires it.

## Interaction states

Every button has:
**Default → Hover → Pressed → Active → Disabled**

Active state must not rely on color alone. Use icon change, fill, indicator, border or glow.

## Shape / accessibility

Major buttons: approximately 48–58px desktop and 52–64px mobile with luxury rounded geometry.

Compact touch controls: minimum 44–48px target; 48px preferred on mobile.

Clear icon/label separation. No wrapped primary labels. Visible keyboard focus. Reduced-motion support. Consistent icon family.

## Glow discipline

Purple glow defines and accents shape; it must not blur the object. Gold is rare and communicates premium value, not general decoration.

## Product launch quality

Before launch, verify:
- first-time user understands what to press within seconds;
- Play is visually dominant;
- Install and Max Level are unmistakable;
- desktop and mobile remain unclipped and non-overlapping;
- one synchronized audio engine controls all playback surfaces;
- search, playlists, queue, favourites, sleep timer, sharing, install, topic request and persistence are real;
- media session and lock-screen controls work where supported;
- content/artwork manifests are consistent;
- accessibility and trust disclosures are present;
- analytics exist for meaningful actions;
- performance remains responsive in long sessions;
- the product behaves like a coherent premium application, not compressed desktop software.

## Engineering rule

The player may be visually luxurious, but visual polish never overrides correctness, accessibility, trust, performance or maintainability.
