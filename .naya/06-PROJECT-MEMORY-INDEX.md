## MEMORY RULE
Conversation is temporary. Repository memory is durable.
A decision that is important enough to affect future work should be written down.

## MEMORY QUALITY
Good memory is:
- Specific
- Current
- Actionable
- Scoped
- Date/version aware when needed
- Linked to related files

Avoid dumping raw conversation transcripts into memory. Capture decisions, rationale, constraints, and acceptance criteria.
