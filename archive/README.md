# MAXESS ARCHIVE

Historical and superseded artifacts belong here.

Active work must not depend on archived versions. The archive exists to preserve history, experiments, and prior implementations without allowing them to compete with the current source of truth.

Migration policy:

1. Identify the current canonical source.
2. Move superseded versions into this folder without deleting history.
3. Update references so active builds use only current-ui and current source files.
4. Never use archived artifacts as implicit production dependencies.
