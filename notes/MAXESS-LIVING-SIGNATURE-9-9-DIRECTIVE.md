# MAXESS Living Signature — 9.9 Execution Directive

## North Star
Results is a moment of recognition, not a report. The user should see a visual representation of their own five-dimensional AI mastery pattern that feels alive, premium, useful, and unmistakably MAXESS.

## Signature system
The primary visual is a **Living Signature**: a deterministic flowing light fingerprint generated from the authoritative MAXESS result object. At its center is the **Resonance Orb**, a breathing luminous core.

- Overall score controls baseline luminosity and energy.
- The five dimension scores control the geometry and flow of the signature.
- The strongest dimension provides a restrained accent influence.
- Dimension labels remain hidden until the user reveals/explores the pattern.
- The same result must always produce the same visual family; animation may vary subtly, but the underlying geometry is data-driven.

## Naya synchronization
When the user plays Naya's result narration, the Resonance Orb becomes her visual heartbeat. Audio amplitude is smoothed through Web Audio API analysis for subtle physical response. Semantic narration events should be represented as an optional timeline in the result model so important insights can trigger meaningful dimension emphasis and stronger pulses. Never make it a generic music visualizer.

## Technical principles
1. One authoritative result object.
2. No DOM scraping for score/state.
3. MAXESS remains independent of NayaNET technical debt.
4. Existing NayaNET page remains the ground-floor foundation at the bottom of the page.
5. Use Canvas/SVG for the signature and supporting visualization where appropriate.
6. Respect reduced-motion preferences and maintain mobile performance.
7. Meaningful motion only: breathing, reveal, recognition, dimension emphasis, Naya synchronization, completion pulse.
8. Preserve the existing NayaNET visual language so the new upper experience feels like the same product, not a separate microsite.

## Design judgment
Ara's strongest proposal was the Living Signature. The team synthesis is to combine it with the Resonance Orb and Naya voice synchronization. We reject random particles, excessive neon, generic dashboard widgets, and audio-reactive effects that behave like a music visualizer. Luxury comes from restraint, hierarchy, optical balance, precision, and meaningful motion.

## Acceptance test
The experience should make the user think: **“This represents me.”** A successful result is not merely “pretty”; the visual itself changes because of their data, Naya responds to that same data, and the next action follows naturally into mastery.
