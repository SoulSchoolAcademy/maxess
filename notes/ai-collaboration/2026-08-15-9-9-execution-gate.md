## Decision

## Execution principle

Ara's answers are advisory. They will be evaluated against CURRENT-TRUTH, NAYA-MASTER, SCORECARDING-MASTER-SYSTEM, the locked MAXESS Results specification, technical constraints, accessibility, and actual evidence.

1. Establish authoritative result schema and state contract.
2. Make Results renderer consume only that contract.
3. Remove DOM scraping as a source of truth.
4. Preserve NayaNET visual language and ground-floor experience while isolating its legacy state.
5. Engineer the five-stage cinematic journey.
6. Build the signature personal-DNA fingerprint around real result data.
7. Add true five-dimension synthesis and one immediately actionable next move.
8. Pass the exact result object into Naya.
9. Verify mobile, accessibility, performance, and state integrity.
10. Run adversarial scorecarding and only claim 9.9 if evidence earns it.

## Gate definition

9.9 is not a CSS quality label. It requires excellence across recognition, comprehension, personalization, action, continuation, visual craft, architecture, accessibility, performance, maintainability, and evidence.
